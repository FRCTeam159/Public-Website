Welcome to the repository hosting the code for the Alpine Robotics website!

# How to develop

The website contents are defined in the "/site" directory.  All files pertaining to the website go in that folder.

TO make a change, check out this repository and create a new branch.  Make changes as desired, and then push your changes.  Create a "Pull Request" in github.

There is automation that will create a preview version of the site for all pull requests.  This will allow you to see how the website looks in its hosted form.  It will also allow team members or mentors to review the change.

Once the pull request is approved (by 2 people at least one of which must be a mentor), The changes will be automatically deployed.

The list of mentors required to make changes is in the CodeOwners file, and currently includes:
